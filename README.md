# Homelab Documentation
This repository contains documentation of my personal home lab.
The goal of this lab is to learn, practice and demonstrate real-world skills
related to Linux, networking, Docker, virtualization and infrastructure documentation.

The repository is designed to be:
- easy to understand
- reproducible
- useful as a portfolio for technical roles

---


## Lab Goals

- Learn and practice self-hosting services
- Understand and document home networking
- Manage Docker workloads using Docker Compose
- Prepare for future expansion with Proxmox and virtual machines
- Prepare for kubernetes cluster
- Build clean, readable technical documentation (Markdown + diagrams)
